# 学习分支图 · LoomTree

![DeepSeek Harness](https://img.shields.io/badge/DeepSeek%20Harness-0.2.x-5b21b6)
![tests](https://img.shields.io/badge/tests-144%20passing-2ea44f)
![license](https://img.shields.io/badge/license-MIT-blue)

把 DeepSeek Harness 里的问答会话整理成一棵可编辑的知识点树：

- 输入框上方常驻一条 `🌳 N节点` 细条，边聊边看；
- 右侧栏打开「学习分支图」，得到可缩放、可拖拽、可改关系的节点画板；
- 点节点跳回对应的原提问。

父子关系先按规则计算（提问里的术语、上下文），再由 LLM 复核明显挂错的分支；
节点标题也可以由 LLM 起一个完整知识点名。模型不可用时全部退回规则结果，不影响建树与跳转。

## 功能

- **两个视图**：输入框上方的缩进列表（轻量）、右侧栏的节点图（全貌）
- **节点图**：缩放 / 平移 / 拖拽节点 / 双击改名 / 拖底部圆点改父子关系 / 点选连线后断开 / 按分支折叠
- **关系复核（默认开启）**：规则树交给 LLM 检查一遍，顶层主题保持不动、只调整非根节点的父子关系；
  不满意时点「仅规则」退回规则关系，或点「重排」重新跑一遍
- **长会话完整展示**：打开图时自动补全更早的历史，不需要回聊天里反复点「加载更早」
- **画板底纹**：点阵、纯色，或任意图片（遮罩、透明度、模糊、铺满/平铺可调）
- **本地优先**：编辑、命名缓存、底图都只存在本机；模型密钥不会下发到页面

## 安装

要求：DeepSeek Harness **0.2.x**（支持 bundle 插件），`desktop` profile。

```bash
git clone https://github.com/8946ben/dsh-loomTree.git
```

克隆后，在 DSH 里把这个目录作为 bundle 安装（插件管理器，或让 agent 执行
`plugin_manager` 的 `install_bundle`，`target` 指向克隆目录）。安装后在插件管理器里
确认「学习分支图」处于启用状态，再刷新页面（`Ctrl+R`）。

卸载：在插件管理器里移除 `@learnmap/web-plugin`（或 `plugin_manager` 的 `remove_bundle`）。

## 配置（可选，影响节点标题与关系复核）

命名和关系复核都走宿主的 `ctx.llm`，需要在 profile 补丁层指定 provider 与 model：

```yaml
# ~/.dsh/profiles/desktop/cordis.patch.yml
- id: learnmap
  config:
    enabled: true
    provider: zai            # 改成你 profile 里已配置的 provider
    model: glm-5.3-flash     # 该 provider 下的模型
    # relate: false          # 不想让 LLM 复核父子关系时关掉（默认开启）
    # 以下仅在 ctx.llm 不可用时作为直连兜底，通常不需要
    # apiKey: '...'
    # baseUrl: https://open.bigmodel.cn/api/paas/v4
```

- 不配置 `provider` / `model` 时会使用 `zai` / `glm-5.3-flash`；你的 profile 里没有这条通路时，标题会退回规则命名。
- 关系复核会随着新提问自动跑；顶层主题（根节点）保持不动，非根节点可以带着子树调整。不满意时点「仅规则」退回规则关系，或点「重排」重新跑一遍。
- 一旦你手动拖过任何父子关系，复核会自动让位给人工布局，不会和你的结构混在一起。
- `apiKey` 只放在本机 profile 补丁层，**不要提交到仓库**；页面侧拿不到密钥。
- 关闭全部模型能力：

```yaml
- id: learnmap
  config:
    enabled: false
```

命名结果会按提问文本缓存（页面 `localStorage` + `~/.dsh/storages/learnmap/labels-v2.json`），
同一个提问不会重复调用模型。关系复核按「节点集合」缓存，节点不变就不会重复请求；
手动拖动改过的关系永远优先于 LLM 的修正。

## 使用

### 输入框上方的细条

- 显示节点总数，点击展开缩进列表；
- 右侧图标：打开侧栏节点图 / 全部展开 / 全部收起；
- 点节点跳回对应提问。

### 右侧栏节点图

| 操作 | 效果 |
| --- | --- |
| 左键拖空白 / 中键拖任意处 | 平移画板 |
| 滚轮 | 平移画板 |
| `Ctrl` / `⌘` + 滚轮 | 以指针为锚点缩放（0.3×–1.8×） |
| 双击空白 | 适宽并归位 |
| 拖动节点 | 只移动这个节点，**不会触发整图缩放或重新排布** |
| 双击节点 | 就地改名（`Enter` 提交 / `Esc` 取消） |
| 拖节点底部圆点 → 目标节点 | 建立 **当前节点 → 目标节点** 的父子关系（目标顶部入点高亮） |
| 拖节点底部圆点 → 空白处 | 取消连线，不改任何关系 |
| 点击连线 | 选中（线变粗、变主题色） |
| 选中后 `Delete` / `Backspace` / 顶栏「断开」 | 删除这条父子关系，子节点变顶层 |
| `Esc` | 取消选中 / 取消正在拖的连线 |
| `重排` | 清掉手动关系与位置（**保留手动改名**），重新跑一遍：规则关系 + LLM 复核 |
| `仅规则` | 清掉手动关系与位置（**保留手动改名**），只使用规则关系，本会话不再请 LLM 复核 |

拖出连线时，所有卡片顶部会显示**入点**，合法目标的入点会高亮，预览线直接吸附到它的顶部；
松手在目标卡片任意位置都算命中。拖动节点只改它自己的位置，不会触发整图重排。

**新增一个问题时，默认只给这个新节点找位置，已有节点的结构保持不动**；只有点「重排」才会把整棵树重新复核一遍。

关系复核不再反复发送整篇回答：每个节点先由模型生成 **200–4000 字摘要**并缓存，关系判断只读摘要；
如果模型认为摘要不够（或新节点摘要过短），会请求这些节点的**原文**，第二轮补上再给最终关系。
这样长会话的请求前缀保持稳定，也能在摘要丢失细节时用原文兜底。

「重排 / 仅规则」都会把关系图恢复到“初始生成”的状态：手动拖过的父子关系、固定位置全部丢弃；
**手动改过的名字会保留**。区别只在于「重排」会再跑一次 LLM 复核，「仅规则」不会。

标题栏的状态：`关系复核中…`、`关系已核对`（模型看过、认为无需调整）、`关系已校正`（模型改过）、
`关系复核失败`、`仅规则`。关系复核在检测到手动关系后会整体让位，直到你点「重排」。

折叠按钮在悬停节点时出现（分支已收起时常显）。

### 画板外观（⚙）

- **点阵**：密度细/中/粗，深浅可调；
- **纯色**：仅主题背景；
- **图片**：点「选择图片」，或直接把图片拖进画板 / 复制后 `Ctrl+V`；支持遮罩强度、透明度、模糊、铺满或平铺。

图片会自动压到长边 1600px 后存进本机，不会上传。

### 长会话

DSH 的会话窗口是分页加载的，所以打开图时会自动向前补齐更早的问答，直到完整（最多 24 页 / 45 秒）。
顶部会显示补全进度，可随时「停止」；没补完时可以「继续加载」。

## 数据与隐私

| 内容 | 位置 |
| --- | --- |
| 细条展开状态 | `localStorage['learnmap.open']` |
| 改名 / 关系 / 手动位置 | `localStorage['learnmap.edits.v1']`（按消息 id） |
| 画板外观与底图 | `localStorage['learnmap.board.v1']`（图片为 dataURL） |
| 节点标题缓存 | `localStorage['learnmap.llm.labels.v2']` + `~/.dsh/storages/learnmap/labels-v2.json` |
| LLM 关系复核缓存 | `localStorage['learnmap.llm.relations.v8']`（按节点集合签名） |
| 回答摘要缓存 | `localStorage['learnmap.llm.summaries.v1']` + `~/.dsh/storages/learnmap/summaries-v1.json` |

模型密钥只存在 profile 补丁层；宿主路由只接受回环请求，`/learnmap/llm.json` 不会回传密钥。

## 常见问题

**节点标题是半句话或提问原文？**
说明当前用的是规则命名：确认 `provider` / `model` 已在 profile 中配置，且标题栏没有「命名失败」提示。

**节点挂错了父节点？**
关系复核会随新提问自动跑，顶层主题保持不动，非根节点可以调整；想退回规则关系点「仅规则」，
想重新请模型复核点「重排」。也可以直接手动改：拖底部圆点换父节点、点连线后 `Delete` 断开。
手动改过之后，关系复核会自动停用。想彻底关闭复核，在配置里写 `relate: false`。

**改完关系后整棵树跳来跳去？**
手动改关系会先固定当前布局，节点不再重排；想丢掉手动布局并重跑一遍就点「重排」。

**刚打开图时节点不全？**
会自动补全历史；若停在「还有更早的问答未加载」，点「继续加载」。这只影响图的数据量，不会改动会话内容。

**单链表分支的连线拐了一下？**
通常是节点被手动拖过，位置优先于自动布局；点「重排」丢掉手动布局并重新排列。

**点节点没有跳转？**
该提问可能被压缩、已被编辑，或尚未加载到当前窗口；稍后再试或先打开该段历史。

**底图保存失败？**
图片会先压到长边 1600px；如果浏览器存储配额仍然不够，换一张更小的图。

## 开发

仓库根目录就是插件包，无构建步骤，浏览器半区是单文件 `client.js`：

| 文件 | 说明 |
| --- | --- |
| `index.js` | 宿主半区：四条回环路由（配置、命名、摘要、关系复核） |
| `client.js` | 浏览器半区：两个挂载点、建树、摘要/关系修正、布局、画板与样式 |
| `cordis.patch.yml` | bundle 插入的插件行 |
| `locale/`、`icon.svg` | 插件管理器的标题、描述与图标 |
| `smoke-test.cjs` | 离线冒烟测试（145 条） |
| `flow-test.cjs` | 关系流程测试（摘要缓存、need 原文、增量复核，8 条） |
| `llm-smoke.cjs` | 命名链路自检 |

```bash
node --check client.js
node smoke-test.cjs        # 期望「全部通过」145 条
node flow-test.cjs         # 期望 flow-test: 8 assertions passed
```

改 `client.js` 后刷新页面（`Ctrl+R`）即可；改 `index.js` 需要重载插件行或重启应用。
